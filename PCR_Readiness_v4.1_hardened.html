📖 How to use this tool. This version stores all data in a single shared JSON file. Optionally encrypt it with a team password using the 🔒 Set Password button before saving. Read the Shared-File Setup section first.

⭐ Shared-File Setup (read this first)

1
Put two files in your team's shared folder: this .html file and the pcr-data.json file. They can sit side by side in the shared OneDrive/SharePoint folder everyone can reach.
2
Open the .html in Chrome or Edge on Windows. (The shared-file feature is not available in iPhone/iPad Safari — those devices fall back to a local, non-synced copy.)
3
Optional — set encryption: click 🔒 Set Password and enter your team's shared password. All teammates must use the same password. Share it securely out-of-band.
4
Click 📂 Open shared file and select pcr-data.json. The status pill at the top turns green. You only do this once per session.
5
Work normally. Every Save writes straight to the shared file. Use ↻ Reload to pull the latest if you've had it open a while.
6
One editor at a time is safest. The tool warns you if the file changed since you opened it — click Reload before saving if you see that warning.

Quick Start — Adding Records

1
Open the PCR Tool tab and tap + Add PCR. Fill in the PCR ID, equipment, component, forecast date, and WO number.
2
Set each gate's status (G1–G9) using the dropdown inside each gate card. Add the owner and notes.
3
Tap Save Record. The PCR appears with a live readiness bar and color-coded gate dots.
4
If any gate is Blocked, go to the Exceptions Log and tap + Log Exception within 4 hours.

What Each Tab Does

Dashboard
Read-only · Auto-refreshes
Live summary: total PCRs, average readiness, open critical blockers, and ready-to-install count, plus a blocked-gates bar chart, a readiness donut, and the Overdue & Blocked Queue.
PCR Tool
Primary edit view · Gate owners
Add, edit, and delete PCR records. Each row shows a nine-dot gate strip, readiness bar, bottleneck gate, and ready status. Search and filter by status.
Component Inventory
Logistics / materials
Catalog of physical components: location, status, quantity, lead time, supplier, inspection dates. Low qty highlights amber; overdue inspections highlight red; retired rows dim.
Exceptions Log
Gate owners · Supervisors
Log blockers, link to PCR ID and gate, assign severity and owner, track Open → Monitoring → Escalated → Resolved. Items open >7 days show age in red.

Reading the Gate Dot Strip

Each PCR row shows 9 colored squares (G1 → G9). Hover a dot to see its name and status.

The Bottleneck column is the first gate not Complete or N/A. Ready = Yes only when all 9 dots are green or blue.

Gates Reference (G1–G9)

G1 ScopeWork scope defined, signed off, baselined.
G2 PartsAll replacement parts staged and inspected.
G3 ToolsSpecialty tooling confirmed and on-site.
G4 CraneLifting equipment scheduled; rigging plan approved.
G5 LogisticsTransport, access, permits confirmed.
G6 MachiningMachining/fabrication completed and QC'd.
G7 StagingEquipment and materials staged in install area.
G8 ExecutionCrew, contractors, schedule confirmed.
G9 QCQuality control plan in place; inspector assigned.

Status & Severity Quick Reference

Gate Status

  • Not Started Work not begun. Default.
  • In Progress Active work; update weekly.
  • Blocked Cannot proceed. Log exception within 4h.
  • Complete Criteria met and verified.
  • N/A Not applicable. Reason in notes.

Exception Severity

  • Critical Delays install in 24–48h.
  • High Delays install within the week.
  • Medium Risk of delay; monitor daily.
  • Low Informational; no schedule impact.
